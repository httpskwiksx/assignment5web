# Assignment 5 — JavaScript Basics (DOM Manipulation & Events)

**Student:** Ulzhan Musakhan  
**Group:** SE-2524  
**Course:** Web Technologies (Frontend)

## Description

Nine separate tasks demonstrating basic JavaScript, DOM manipulation, and event handling. All pages are connected by a navigation bar. The scripts use plain JavaScript and the HTML/CSS is kept simple.

## Tasks

- Task 0 — First Script: console.log name and group, alert message.
- Task 1 — Variables & Operators: string, number, boolean, arithmetic and string concatenation in the console.
- Task 2 — Changing Content: a button changes paragraph text.
- Task 3 — Changing Styles: buttons change a block's background and font size.
- Task 4 — Creating & Removing Elements: add and remove list items.
- Task 5 — Mouse Events: mouseover and mouseout change box color.
- Task 6 — Keyboard Events: keyup displays typed text.
- Task 7 — Calculator: addition, subtraction, multiplication, and division.
- Task 8 — Interactive To-Do List: add, complete and delete tasks; tasks are stored only in a JavaScript array.

## Project Structure

- `index.html` — Task 0
- `task1.html` to `task8.html` — Tasks 1–8
- `CSS/style.css` — Shared styles
- `JS/task0.js` to `JS/task8.js` — Scripts for each task

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a browser (or use Live Server in VS Code).
3. Use the navigation bar to open each task.
4. For Tasks 0 and 1, press `F12` and open the browser's **Console** to see the output.

## Publish with GitHub Pages

In the GitHub repository, open **Settings → Pages**. Choose **Deploy from a branch**, select the `main` branch and the `/ (root)` directory, then save. Use the generated URL to test all pages.

## Notes

This is a frontend-only educational project. The calculator runs in the browser and the To-Do list stores tasks in an in-memory array (no backend or localStorage). Refreshing the page clears To-Do tasks.
